How I write my JIRA tickets

Value Statement

  • As an SRE, I would like to do X.
  • This allows our team or stakeholders to do Y.
  • Which brings benefits in terms of Z.

Problem Space

  • Currently, we have identified the problem: (some problem)
  • This leads to (some undesired effect)
  • This causes (some specific pain) to (relevant stakeholders)

Solution Space

Describe the proposed solution, design approach, or implementation plan here.

Priority

  • Based on (shared reasons), this ticket has been prioritized for execution.

Stakeholders

  • Engineers
  • Leads
  • Other relevant personnel

Due Date

Specify target completion date.

Definition of Done

This ticket is considered complete when Z is achieved through implementation of the defined solution space.

Acceptance Criteria

  • Criteria 1
  • Criteria 2
  • Criteria N
